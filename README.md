# 🦐 癒し水槽 ― 海老育成ゲーム

ブラウザで動くリアルな水中シミュレーションゲームです。  
Canvas 2D で描画された美しい水槽の中で、3種のシュリンプ・熱帯魚・巻貝を育てましょう。

🔗 **プレイはこちら → [https://junia2009.github.io/my_aquarium/](https://junia2009.github.io/my_aquarium/)**

## ✨ 特徴

- **単一HTMLファイル** — 外部ライブラリ不要、`index.html` だけで完結
- **リアルな水中表現** — Beer-Lambert 法による光の減衰、コースティクス、ゴッドレイ、パーリンノイズの砂底
- **解剖学的に正確なエビ** — ベジエ曲線で描画された3種のシュリンプ
- **生態系シミュレーション** — エビ・熱帯魚・巻貝が共存する小さな水槽
- **本格的な育成システム** — 空腹・HP・水温・水質・病気・繁殖・寿命をシミュレート
- **オートセーブ** — 60秒ごとに自動保存。手動セーブ/ロードも可能
- **レスポンシブ対応** — スマートフォン（縦向き）、タブレット、デスクトップに対応
- **PWA 対応** — ホーム画面に追加してアプリのように使える
- **BGM** — Web Audio API による環境音楽（4レイヤー合成）

## 🎮 操作方法

画面下の **▲ メニュー** ボタンをタップすると、操作グリッドが開きます。ボタンを押してもメニューは開いたままなので、連続操作も快適です。

| ボタン | 機能 |
|--------|------|
| 🍤 **餌** | 通常フードを投下（満腹度 +15） |
| 🥬 **野菜** | 野菜を投下（満腹度 +10、腐りにくい、水質に優しい） |
| 💧 **水換え** | 水質 +30、コケも一部除去 |
| 🌡️ **ヒーター** | ON/OFF 切替。ONで水温を25℃に維持 |
| ⚙️ **ろ過** | ON/OFF 切替。ONで水質の自然浄化をサポート |
| 💡 **照明** | AUTO（7〜19時）→ ON（常時点灯）→ OFF（消灯）の3段階 |
| 🔇 **BGM** | 環境音楽のON/OFF |
| 🛒 **エビ追加** | ランダムな種類のエビを1匹お迎え（最大12匹） |
| 🐟 **魚追加** | ランダムな熱帯魚を1匹お迎え（最大5匹） |
| 💾 **セーブ** | 現在の状態を保存 |
| 📂 **ロード** | 保存済みデータを読み込み |

上部パネル右の **エビ情報** をタップすると、各個体のHP・満腹度の詳細表示が展開できます。  
水質・水温・HP・満腹度のゲージにマウスホバーで具体的な数値がツールチップ表示されます。

## 🐛 ゲームシステム

### 生命管理
| 要素 | 説明 |
|------|------|
| **空腹度** | 時間経過で減少。20以下でHP低下。餌を食べて回復 |
| **HP** | 0でエビが死亡（浮上＋フェードアウト）。水質・水温・空腹で影響 |
| **寿命** | 約3日（2.75〜3.25日）。寿命80%で老齢通知、超過すると老衰死 |
| **老化** | 寿命60%超で見た目が徐々に白っぽく変化 |
| **脱皮** | 5〜10分間隔で発生。水質・水温が悪いと **脱皮失敗** のリスク（HP -40） |
| **抱卵・孵化** | 条件が揃うとメスが抱卵 → 60〜100秒後に2〜4匹の稚エビが誕生 |
| **病気** | 水質・水温悪化で発症リスク。近くのエビに**伝染**。60〜120秒で自然回復 |

### 水質管理
| 要因 | 水質への影響 |
|------|-------------|
| 自然劣化 | ベース -0.012/秒 |
| バイオロード | -0.0015/秒/匹（エビ） |
| 熱帯魚 | -0.001/秒/匹 |
| 残餌腐敗 | 30秒放置で腐敗開始 → -0.005/個/秒 |
| 脱皮殻 | -0.002/殻/秒 |
| 死体 | 即時 -8 |
| 排泄 | 食後15〜30秒後に -0.3 |
| 水草浄化 | +0.0016/本/秒 |
| 巻貝の浄化 | +0.0022/匹/秒（タニシ・ラムズホーン） |
| ろ過装置 | +0.018/秒（ON時） |

### 環境システム
| 要素 | 説明 |
|------|------|
| **水温** | 季節に連動（1月=8℃〜7月=32℃）。適温は22〜26℃ |
| **ヒーター** | ONで25℃に自動維持 |
| **照明** | AUTO（JST 7〜19時で自動点灯）/ ON / OFF の3モード |
| **昼夜サイクル** | 消灯時は青黒い夜の演出＋ほのかな月光 |
| **コケ** | 照明で成長し、ガラスに緑の苔が付着。水換えで一部除去。エビが自然に食べることも |
| **隠れ家** | 流木風シェルター2つが自動配置。過密ストレスを軽減＋微量HP回復 |
| **過密ストレス** | 9匹以上でHP低下（隠れ家で軽減可能） |

### セーブ／ロード
- **オートセーブ** — 60秒ごとに `localStorage` へ自動保存
- **起動時復元** — 前回のデータがあれば自動的に読み込み
- **手動セーブ/ロード** — メニューからいつでも実行可能

## 🦐 生き物の種類

### シュリンプ（最大12匹）
| 種類 | 特徴 |
|------|------|
| **ビーシュリンプ** | 赤白バンド模様。やや機敏。初期3匹 |
| **クリアシュリンプ** | 透明ボディ。他のエビについて行くことがある。初期2匹 |
| **黒白縞シュリンプ** | 黒と白のコントラストが美しい縞模様。初期1匹 |

### 熱帯魚（最大5匹、装飾的）
| 種類 | 特徴 |
|------|------|
| **ネオンテトラ** | 青く光るストライプ。群泳。初期3匹 |
| **グッピー** | カラフルな扇尾。色は個体ごとにランダム |
| **ラスボラ** | 黄金色のボディに楔形マーク |

### 巻貝（合計4〜12匹を自動維持）
| 種類 | 特徴 |
|------|------|
| **タニシ** | 黄褐色の渦巻き殻。砂底をゆっくり移動 |
| **ラムズホーン** | 平たい巻き貝。コケや残餌を食べて水質を改善 |

巻貝は水質に応じて自動繁殖・淘汰されます（水質が低いほど繁殖、高すぎると餓死）。

### エビの行動
- **ツマツマ** — 前脚で地面をつつく
- **歩行** — 水草の近くを散策
- **遊泳** — 水中を泳ぎ回る
- **浮遊** — ゆったり漂う
- **食事** — 落ちた餌に向かって移動して食べる
- **追従** — 他のエビの後を追う（クリアシュリンプ）

## 🚀 セットアップ
